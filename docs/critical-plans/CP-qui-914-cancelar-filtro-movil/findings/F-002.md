# F-002 — Fallo de cancelación envuelto en HTTP 200

- **Proposed fix:** Agregar B.3 para relanzar únicamente ese error al filtro global y probar que otros PATCH mantienen el contrato previo.

Se agregó spec de regresión. El spec no ejecutó por el fallo preexistente de tipos `sharp`, registrado en `evidence/implementation-verification.md`; verificación runtime pendiente.
