# F-006 — Acción destructiva requiere número de orden

- **Scenario:** Varias tarjetas muestran un botón destructivo llamado igual; lector de pantalla no distingue la orden.
- **Proposed fix:** Pasar `rowLabelKey=order_number` y comprobar el nombre accesible.
- **Resolution:** B.1 pasa `rowLabelKey="order_number"`; `ItemListComponent.getActionAccessibleName()` combina el label «Cancelar orden» con el número. Evidencia estática: `evidence/implementation-verification.md`.
