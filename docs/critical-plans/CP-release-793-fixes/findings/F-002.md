# F-002 — Metrica de abandonados lee cero estructural

- **Scenario:** Los 5 queries filtran `state = 'abandoned'` + `EXISTS items`, pero nada escribe ese estado (cart escribe `active`/`converted`; el expiry borra items sin tocar `state`; migracion declara 0 rows). La combinacion es inalcanzable: summary/trends/export devuelven `abandonment_rate = 0%`.
- **Proposed fix:** ADR-01: derivar en SQL (`active` + `last_activity_at` antiguo + con items) en vez de depender del estado almacenado. Actualizar QUI-628 (Devuelto) con el hallazgo.
