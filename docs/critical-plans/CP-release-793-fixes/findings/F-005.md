# F-005 — Checkout preselecciona primera tarifa contra comentario

- **Scenario:** `shippable.find(postal_code_match) ?? shippable[0]` preselecciona la mas barata sin codigo postal, mientras el comentario exige eleccion explicita. `canConfirmOrder` sigue bloqueando confirmar sin metodo: no hay bypass, pero la conducta documentada ya no existe.
- **Proposed fix:** Directiva de usuario + ADR-03: NO tocar la logica (mostrar todas, preseleccionar mejor match como sugerencia cambiable). Solo reescribir el comentario y verificar que la seleccion es cambiable sin bloqueo.
