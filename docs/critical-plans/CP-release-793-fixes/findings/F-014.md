# F-014 — base_cost con OR-cero enmascara NaN

- **Scenario:** `Number(values.base_cost) || 0` convierte `NaN`/`''` en 0 silencioso, mientras el resto del metodo usa `parseNullableNumber` explicito. El DTO backend acepta la forma enviada: no rompe, pero es fragil.
- **Proposed fix:** Directiva de usuario: misma linea que el resto del metodo (parse + error visible si no es numero).
- **Resolution:** fixed: 68e4d0adc parse + error visible (patron baseCost).
