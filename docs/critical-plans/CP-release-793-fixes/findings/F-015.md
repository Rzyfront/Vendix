# F-015 — parseInt sobre ids tipados string

- **Scenario:** `parseInt` sobre `OrganizationConfig.id` y `StoreConfig.organizationId` (ambos `string`): parse parcial ("12ab"→12) y `NaN` que viaja como `null`. El backend lo tolera (`@IsOptional()` + fallback por `store_id`): no rompe, pero es fragil.
- **Proposed fix:** Directiva de usuario: `Number()` + guard `Number.isInteger`.
