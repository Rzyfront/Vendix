# F-006 — Listener PQR no matchea roles canonicos

- **Scenario:** `notifySuperAdminsOfResponse` usa `roles.name = 'SUPER_ADMIN'` exacto, pero el canonico es `'super_admin'` (seed + enum): los avisos de respuesta a superadmins no matchean a nadie. La rama store de `response_sent` solo matchea `'STORE_ADMIN'` literal mientras el resto usa owner/admin/manager.
- **Proposed fix:** Directiva de usuario: extraer constante compartida de roles destino y reusarla en los 3 sitios (misma linea que el fix ya aplicado en `handlePqrCreated`).
- **Resolution:** fixed: 68e4d0adc constantes compartidas de roles en los 3 sitios + spec nuevo 6/6.
