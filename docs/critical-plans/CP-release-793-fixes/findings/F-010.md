# F-010 — Header de notas contradice derivacion por kernel

- **Scenario:** El docblock dice mandar `taxes` o la DIAN rechaza, pero `buildNotePayload` los omite a proposito (F-073) porque el backend deriva por kernel. El comportamiento parece correcto, pero tocar impuestos de NC/ND sin validar normativa es critico: exige validacion DIAN profunda antes de reescribir nada.
- **Proposed fix:** Directiva de usuario: validacion normativa detallada (UBL, totales vs lineas, `derivePartialNoteLinesViaKernel`, specs) con evidencia, y solo entonces reescribir el header al contrato validado. Ver ADR-06. Comentar en QUI-702.
- **Resolution:** fixed: header reescrito por humano en efecea5e5; validado por matriz DIAN (R.2) y no-op B.3; QUI-702 comentado.
