- Migración `20260805120000_carts_abandoned_state`: header declara `Expected row changes: 0 rows updated. All new columns are NULLABLE without defaults` — carritos preexistentes leen `state=NULL`.
- `clearCartIfExpired` (`cart.service.ts`): borra `cart_items` sin tocar `state` (además deja `subtotal: 0`).
