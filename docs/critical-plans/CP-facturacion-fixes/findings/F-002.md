# F-002 — whatsapp-sin-gate-de-envio

- **Scenario:** `whatsappCheckout` with physical items and no `shipping_rate_id`/`shipping_method_id`
  creates the order with nulls and `delivery_type='other'`. `ORD_SHIP_REQUIRED_001` exists only in
  `checkout()` (`:1214`). Dispatch and fiscal documents downstream receive shippyless orders.
- **Proposed fix:** ADR-02: keep creation open; require method+rate at charge/invoice time with a
  registered error code.
- **Resolution:** fixed on branch fix/CP-facturacion-fixes, evidence in log/execution.md
