# F-038 — Tenant público atacante-controlado sin proyección allowlist

- **Scenario:** `/ecommerce/catalog` es `@Public()` y el middleware acepta `x-store-id`/query/host sin ownership: `?search=a&store_id=2,3…` enumera productos/precios de toda tienda. D.3 reutiliza "mismo helper" sin proyección pública: si filtra forma admin (costos, tax_map, stock, márgenes) el scrapeo cosecha datos no-públicos.
- **Proposed fix:** Contrato de proyección pública (allowlist, costos/tax/stock interno fuera, spec diff público-vs-admin) + missing-tenant 404/400 en service + throttle + cap 4 tokens + gate p95.
