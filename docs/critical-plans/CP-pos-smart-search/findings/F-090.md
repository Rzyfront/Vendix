# F-090 — Sin admission control en path search

- **Scenario:** Pool `max 10` default sin `statement_timeout` ni timeout por query, compartido tenants×endpoints. Un search patológico retiene conexión segundos; un puñado encola el pool y el plan no distingue "search saturando pg" de lentitud genérica: la primera señal prod serían timeouts de checkout, no alertas search.
- **Proposed fix:** `statement_timeout` en path search (mínimo raw C.3) + métrica profundidad cola pool/latencia search como gate junto a p95 + headroom analysis (max conns vs RDS) antes de flags en tiendas grandes.
