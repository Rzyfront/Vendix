# F-013 — Sin predicado único isSmartSearchActive

- **Scenario:** B.1 gatea where por flag L1 y B.2 rankeaba por `pos_optimized`: admin/bulk/Vexi (sin pos_optimized) reciben set nuevo con orden viejo. Si B.1 también llavea por pos_optimized, findAll≠findIds y DB-17 rompe.
- **Proposed fix:** Predicado puro único `isSmartSearchActive(query, flags)` junto al motor en `common/`, consumido por where y rank; tabla de decisión por caller + spec findAll≡findIds.
- **Resolution:** Fixed in A.1: unique isSmartSearchActive predicate (tier-on + >=1 token), caller decision table, dual-consumption spec.
