# F-037 — Aritmética load-more puede disparar ERR-06

- **Scenario:** Hoy la grilla siempre envía `page=1`; E.1 progresa page/pageSize en cliente y un off-by-one (page 0 en reset-durante-carga, pageSize 0) envía `?page=0` → pasa DTO (sin @Min) → Prisma muere → 200+success:false → cajero pierde items visibles sin toast ni retry.
- **Proposed fix:** Clamp `page>=1, limit>=1` en paginación + unit reset-durante-carga/tamaño-vacío + contratos ERR-06/ERR-13 con UX append (toast + conservar + retry).
