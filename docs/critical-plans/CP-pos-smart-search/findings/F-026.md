# F-026 — Expresión índice sin fijar; GIN sin uso silencioso

- **Scenario:** ADR-04 predica `unaccent(lower(col)) LIKE %token%` pero C.2 no fija la expresión indexada: si difieren, el planner no usa el GIN, todo keystroke sigue seq-scan y el objetivo 8 falla con tests funcionales verdes.
- **Proposed fix:** Expresión canónica única `immutable_unaccent(lower(col))` idéntica en DDL C.2 y SQL C.3; gate automatizado EXPLAIN que aserta `Bitmap Index Scan`, no eyeball manual.
