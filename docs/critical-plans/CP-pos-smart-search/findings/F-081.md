# F-081 — Paridad tokenizer-JS vs SQL sin fijar

- **Scenario:** Si el tokenizer JS emite `café` (acento vivo) y SQL compara contra `immutable_unaccent(lower(col))`, `LIKE '%café%'` jamás matchea la columna sin acento y el objetivo 1 (`cafe`→`café…`) falla solo en Fase B.
- **Proposed fix:** Tokenizer emite minúsculas sin acento byte-idénticas a `immutable_unaccent(lower())` (mismas reglas split/guiones), pineado por fixture compartido con los arrays de tokens de las 4 queries objetivo-1.
