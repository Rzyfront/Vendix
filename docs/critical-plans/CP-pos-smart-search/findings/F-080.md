# F-080 — Metacaracteres LIKE sin escapar (%, _)

- **Scenario:** `search=100%` o `tornillo_M8` trata `%`/`_` como wildcards: devuelve filas que comparten prefijo en vez del token literal, quiebra la precisión token-AND y quema CPU en patrones que el GIN no poda (peor en superficie pública D.3). Consolida P6-F4.
- **Proposed fix:** Escapar `\`, `%`, `_` en cada token + cláusula `ESCAPE '\'` explícita (raw Fase B y matcher memoria Fase A) + specs query literal `%`/`_`.
