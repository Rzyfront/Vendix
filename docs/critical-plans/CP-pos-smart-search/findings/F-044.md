# F-044 — Rank query trae variantes anchas: wire/memory por keystroke

- **Scenario:** ADR-02 exige match en variants.name/sku y B.2 rankea en memoria → la light debe traer texto de variantes de ≤2001 filas: `include` en 2001 rows (2001×variantes×columnas por keystroke) o 2º query batcheado (4º round-trip). Query 2-tokens en tienda 5k×3 variantes ≈ 6000 filas para rankear y descartar 99%.
- **Proposed fix:** Ranking two-tier: light solo columnas producto → score → hydrate top-K (≈100) con variantes y re-score solo esos; edge variant-only bajo top-K documentado (Fase B lo cubre) + assert wire-size/memoria.
- **Resolution:** Fixed in B.2: two-tier (product light, top-K variant re-score); variant-only edge documented.
