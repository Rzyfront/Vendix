# F-051 — Flags por keystroke: +1-2 lecturas DB sin caché

- **Scenario:** Flags en `store_settings` leídos por request (`getSettings()` o `findFirst` directo): cada keystroke paga +1-2 round-trips sin caché contra p95 <250ms. Si se cachea en memoria para salvarlo, "rollback instantáneo" se vuelve "tras TTL/restart" y el reversibility claim miente igual.
- **Proposed fix:** Read path en A.0: 1 select batcheado junto a query existente o caché TTL 30-60s por tienda con invalidación en PATCH; latencia rollback honesta (≤TTL) y p95 presupuestado con lookup incluido.
- **Resolution:** Fixed in A.0: 45s TTL cache + PATCH/reset/template invalidation; honest rollback latency documented.
