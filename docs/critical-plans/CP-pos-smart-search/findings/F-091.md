# F-091 — Rollback claims overprometen ("si no", in-flight)

- **Scenario:** "Flag off sin deploy; si no, git revert" admite que el flag es opcional: sin flags, rollback = revert+redeploy completo, no el "trivial" de ADR-01. Con flags, in-flight completa en path viejo (bien, pero no "instantáneo") y revert Fase B deja GIN/extensiones huérfanas sin paso de limpieza dueño.
- **Proposed fix:** Flags obligatorios (no "si no"), latencia "siguiente request tras toggle (+TTL caché)" y runbook teardown Fase B (orden DROP INDEX/wrapper/EXTENSION + `migrate resolve`) dueño en C.2.
