# F-101 — Verificación índice solo-archivo sin re-check runtime

- **Scenario:** Gate deploy = check manual + EXPLAIN en evidence. Si el GIN queda INVALID, Postgres sirve vía seq-scan (correcto, 10-50× lento) y ningún probe re-valida salud del índice: la regresión aflora como tickets vagos "POS lento" desconectados del deploy. (Loc corregida: aplica a C.3/C.2.)
- **Proposed fix:** Assert `indisvalid=false` en log del deploy linkado al release + EXPLAIN staging (tamaño+fecha) en evidence + probe readiness/startup que warn/paging si el GIN falta o está INVALID.
