# F-005 — Falta contrato de error para cancelar draft con mesa abierta

- **Scenario:** A.4 promete rechazar la cancelación de un borrador ligado a una sesión de mesa abierta con código tipado y mensaje accionable. El registro `registry/err.md` solo lista ERR-38 (reversa de pago); ningún código existente expresa «cierra la cuenta desde Mesas». Implementar el guard sin registrar su contrato produciría un 409 genérico o un código con semántica equivocada, y el frontend no sabría qué mostrar.
- **Proposed fix:** añadir ERR-43 `ORD_CANCEL_OPEN_TABLE_001` (409), con detalle opcional `table_session_id`, mapeo de UI «Cierra esta cuenta desde Mesas antes de cancelar el borrador», prueba de rechazo antes del claim y fila de registry; enlazarlo a A.4 y verificar cero escritura.
- **Resolution:** `d13ce5b79` añadió `ORD_CANCEL_OPEN_TABLE_001` tipado y el guard anterior al claim. API/SQL sobre borrador #1105/sesión #103 confirmó 409, `details.table_session_id` y cero escrituras (`evidence/A4-local-api-verification.md`); Playwright del carril elegible en `evidence/A4-ui-draft-cancel.md`.
