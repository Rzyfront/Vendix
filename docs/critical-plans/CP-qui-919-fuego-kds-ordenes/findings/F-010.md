# F-010 — SSE de órdenes filtra tickets completos a permiso de lectura

- **Scenario:** Usuario con `store:orders:read`, pero sin `store:kitchen_fire:read`, se conecta a `/store/orders/stream` y recibe por el subject compartido `ticket.*` con el ticket completo, incluidas notas de cocina/orden y datos asociados.
- **Proposed fix:** En el stream de órdenes transformar eventos `ticket.*` en envelope allow-listed `{ type, ticket: { order_id }, ts }`; no tocar el stream KDS ni el bus compartido.
- **Resolution:** Pendiente de B.4; verificar que ningún consumidor del stream de órdenes necesita el ticket completo y probar el envelope filtrado.
