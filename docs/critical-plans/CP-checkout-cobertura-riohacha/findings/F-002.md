# F-002 — zona domicilio no matchea pese a existir tarifas

- **Scenario:** `POST /shipping/calculate?store_id=10` con Riohacha/La Guajira/440001 devuelve 1 pickup (`zone_id:5,is_fallback:false`) aunque la tienda configura zonas "Entrega a Domicilio" y "Riohacha" con tarifas gratis activas. `is_fallback:false` prueba que una zona matcheó pero sin tarifa domicilio aplicable, o que las zonas domicilio se descartaron por criterio (región/ciudad/zip/activa).
