# F-001 — prod muestra string de develop sin release a main

- **Scenario:** prod renderiza "No hay envío a domicilio para esta dirección…", string que solo existe en 93365bc55 (develop, NO-EN-MAIN probado con merge-base), mientras ambos deploys disparan solo en push a `main`. O alguien hizo dispatch manual desde develop, o roku-shop se sirve por otro canal.
- **Proposed fix:** fijar runs de deploy (s3 + ec2) y rama desplegada en `evidence/prod-version.md`; a partir de ahí, releases solo vía `main` (ADR-01). Si hubo dispatch manual, queda registrado quién/cuándo.
- **Resolution:** refutado 2026-09-08: el usuario confirmó que las pruebas fueron en local (vhost a local), no en prod. Ver `evidence/prod-version.md`. El skew de deploy queda como hipótesis descartada; ADR-01 sigue válido como regla preventiva.
